## 📌 Overview

This project examines **Audi’s sales performance from 2012 to 2022**, uncovering market trends, seasonality, and external influences. Using statistical and time-series forecasting methods, the study predicts future sales and evaluates model performance.  

**Objectives:**
- Analyze historical sales data to identify trends and seasonality.  
- Apply statistical tests and time-series forecasting models.  
- Generate actionable insights for future sales planning.

---

## 📊 Methodology

### 1. Data Exploration & Statistical Analysis
- Descriptive statistics: mean, median, variance, skewness, kurtosis  
- **Jarque–Bera test** to check normality  
- Autocorrelation analysis using **ACF plots** and **Box–Pierce test**  

### 2. Forecasting Models
| Model | Key Metrics / Notes |
|-------|-------------------|
| Seasonal Naïve | MAE, MSE, MAPE evaluated; **Theil's U = 0.792** |
| Simple Linear Regression | Weak fit (**R² = 0.0519**) but statistically significant (**p = 0.00859**) |
| Holt–Winters Exponential Smoothing | Best-performing model; smoothing factor **α = 0.183843** |
| 3-Period Moving Average | **MSE = 5,297.29** |
| Logarithmic Transformation | Improved regression accuracy |

---

## 📝 Conclusions

- Audi sales show **strong seasonal patterns** and global market sensitivity.  
- Linear regression provides limited predictive power.  
- **Holt–Winters exponential smoothing** produced the most accurate forecasts.  
- Insights can support **strategic sales planning, production scheduling, and market analysis**.
